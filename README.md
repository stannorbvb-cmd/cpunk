# CpUnk — Omarchy Theme

A dark, cyberpunk-inspired theme for **Omarchy**, built around high contrast reds, deep blacks, and a gritty industrial aesthetic.
Designed for Arch Linux + Hyprland users who want a sharp, aggressive desktop that still stays readable and minimal.

## ✨ Features

- 🟥 Cyberpunk red & black color palette  
- 🖥️ Optimized for **Hyprland**  
- 🧠 Consistent colors across Omarchy components  
- 🔤 Tuned for **JetBrainsMono Nerd Font**  
- 🧩 Clean, minimal UI with high contrast

## 🧰 Requirements

- **Arch Linux**
- **Omarchy**
- **Hyprland**
- `JetBrainsMono Nerd Font` (recommended)
